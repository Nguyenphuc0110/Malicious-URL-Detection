AI EXPLAINABILITY

How AI Model Scores Are Calculated

Each model converts a URL into numerical features and calculates a score for the malicious class. F1 and F2 in model names refer to feature sets, not the F1-score and F2-score evaluation metrics.

LOGISTIC REGRESSION

LR-F1 and LR-F2

z = b + SUM(w_i * x_i)
Model Score = 1 / (1 + exp(-z))

x_i: URL feature
w_i: learned weight
b: learned intercept

RANDOM FOREST

RF-F1

Model Score = SUM(P_tree_i(malicious | x)) / T

T: total number of trees.
The score is the average predicted probability for the malicious class across the trees.

XGBOOST

XGB-F1

z = base_margin + SUM(tree_k(x))
Model Score = 1 / (1 + exp(-z))

Each boosted tree contributes to the combined prediction margin for binary logistic output.

SUPPORT VECTOR MACHINE

SVM-F2

margin = decision_function(x)
Score = 1 / (1 + exp(-margin))

This is the backend fallback when predict_proba is unavailable. A sigmoid-transformed decision margin is not necessarily a calibrated probability.

DECISION RULE

How a Model Makes Its Decision

Model Score >= Threshold : Suspicious URL
Model Score < Threshold : No Alert

The backend uses predict_proba(X)[:, 1] when available, or applies a sigmoid transformation to decision_function(X) otherwise.

The table above reports offline test_A metrics for these same five original baseline models. Model Score changes for each scanned URL. Precision, Recall, F1, F2 and FPR do not.
